# Known Limitations

- Production CISC data is not included because no approved workbook or normalized dataset was supplied.
- Official PDF calculation reports are intentionally disabled because the tool-specific approved Report Specification and entitlement integration were not supplied.
- Authentication and subscription providers are represented only as configuration boundaries; no duplicate identity system has been created.
- Class 4 effective-section logic remains unsupported because Agent #2 does not include approved effective-section logic.
- Lateral-torsional buckling logic is not invented; Agent #2 warnings are preserved.
- Connection design remains outside the approved calculation scope.
- Deflection demand is an input from the structural analysis model and the deflection limit is project-specific.
